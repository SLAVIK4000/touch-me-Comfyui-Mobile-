# Каталог workflow-шаблонов

Здесь с этапа 2 интеграции будут храниться шаблоны ComfyUI-графов в
**API-формате** — именно этот формат (`{ "<id>": { "class_type", "inputs" } }`)
принимает `POST /prompt` сервера ComfyUI (UI-экспорт `nodes/links` перед
отправкой нужно конвертировать один раз вручную — через «Save (API Format)»
в редакторе ComfyUI).

Планируемая структура:

```
workflows/
  <id>.json             — граф в API-формате (точная пересборка рабочего workflow)
  <id>.manifest.json   — supportedModes + биндинги «id узла → вход → поле стора»
```

Манифест описывает, какие элементы интерфейса управляют какими узлами;
добавление нового workflow — файлом в этот каталог, без изменения UI-кода
(см. `docs/architecture.md`).
