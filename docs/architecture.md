# Архитектура «Touch me»

Краткая карта слоёв для контрибьюторов. Полную картину фазы 1 (аудит
компонентов, соответствие узлам ComfyUI) проект ведёт во внутренней
документации; здесь — то, что нужно для ориентирования в коде.

## Слои (сверху вниз)

1. **Компоненты UI** — `src/components/touchme/`
   - `TouchMeApp` — корневой контейнер: просмотрщик, шапка, нижняя лента и
     три оверлея (настройки, галерея, полноэкранный промпт). Инициализирует
     соединение с сервером (`useConnectionStore`).
   - `ImageViewer` — жесты: свайп-переключение, двойной тап (зум ×2.2),
     pinch 1–8×, pan, одиночный тап — скрыть/показать интерфейс.
   - `SettingsSheet` + `panels/*` — девять панелей настроек: Модели, LoRA,
     Fooocus-стили, Промпт, Разрешение, KSampler, Режимы, Изображение (img2img),
     Upscale. Состав нижней ленты вычисляется из активных режимов.
   - `GallerySheet` — полноэкранная галерея с переименованием.
   - `TopBar` — статус-чип соединения (ОНЛАЙН/ОФЛАЙН), `BottomBar` — кнопка
     генерации/прерывания и строка прогресса.
2. **Состояние** — `src/store/touchme/` (Zustand), четыре независимых стора:
   - `useAppStore` — UI-состояние (активные панели, режим переименования).
   - `useConnectionStore` — пинг `/system_stats` (ОНЛАЙН/ОФЛАЙН), при первом
     подключении наполняет галерею историей сервера.
   - `useGalleryStore` — изображения галереи: демо-файлы офлайн, реальные
     результаты ComfyUI (сделанные и в классическом UI тоже) после подключения.
   - `useGenerationStore` — режимы обработки и все параметры генерации
     (loaders / loras / ksampler / upscale) И её выполнение: `startGeneration`
     собирает граф, ставит его в очередь и следит за прогрессом.
3. **Слой API** — `src/lib/touchme/api/`
   - `comfy.ts` — HTTP/WS-клиент того же origin: `/object_info`, `/prompt`,
     `/interrupt`, `/history`, `/view`, `/upload/image`, `/system_stats`,
     WebSocket `/ws?clientId=…`.
   - `workflow.ts` — чистая функция `buildWorkflow(state) → граф в
     API-формате` из стандартных нод ComfyUI (CheckpointLoaderSimple, UNET/
     CLIP/VAE Loader, LoraLoader, KSampler, LatentUpscale,
     UpscaleModelLoader, SaveImage, …). Режимы t2i/img2img/upscale —
     это патч связей графа.
   - `gallery.ts` — связка истории сервера и галереи (замеры размеров,
     превращение `/view`-ссылок в элементы галереи).
4. **Источники данных** — `src/lib/touchme/data/sources.ts`
   Единственная точка, откуда панели получают списки: модели/LoRA/сэмплеры/
   шедулеры/методы апскейла — из `/object_info` живого сервера (тот же
   источник, что у выпадающих списков классического интерфейса; на Colab —
   Google Drive, My Drive/ComfyUI/models). Fooocus-стили — из ресурса
   `fooocus_styles.json`. Без сервера — встроенный демо-набор имён
   (`demo_models.ts`) — офлайн-фолбэк, а не эмуляция API.

## Два режима работы

- **Онлайн (кастом-нода в ComfyUI)** — основной режим: корневой `__init__.py`
  регистрирует в `PromptServer` маршруты `/mobile` и `/mobile/{tail}`, которые
  отдают статический бандл из `web/`. Интерфейс ходит в API того же origin —
  без CORS и mixed-content. Пересборка бандла: `scripts/build_comfyui_web.sh`;
  офлайн-проверка маршрутов: `scripts/test_web_serve.py`.
- **Офлайн-демо** — страница открыта без сервера (локальный файл, отдельный
  хостинг): чип «ОФЛАЙН · ДЕМО», демо-списки имён и демо-галерея, кнопка
  генерации сообщает, что сервер не найден.

Контракт с ComfyUI (эндпоинты, WebSocket, форматы, туннели) —
в [`docs/comfy-api.md`](./comfy-api.md).
